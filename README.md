# Harrygrace International Logistics Venture

A modern, premium, fully responsive marketing website for **Harrygrace International Logistics Venture** — a Lagos-based logistics and shipping company delivering cargo from Nigeria to 47+ countries worldwide.

## Key Technologies

| Technology | Version | Purpose |
|------------|---------|---------|
| TanStack Start | 1.x | Full-stack React framework with file-based routing |
| React | 19 | UI rendering |
| Tailwind CSS | 4 | Utility-first styling |
| Vite | 7 | Build tooling |
| TypeScript | 5.7 | Type safety |
| Lucide React | 0.576 | Icon library |

## Sections

1. **Hero** — Full-screen slideshow with animated headline, stats, and CTAs
2. **About** — Company story with animated stat counters and image
3. **Services** — 8 service cards in a responsive grid
4. **Shipment Tracking** — Interactive tracking UI with demo progress animation
5. **Why Choose Us** — 6 feature highlights with split layout
6. **Global Coverage** — Animated SVG world map with city markers and route lines
7. **Testimonials** — Auto-playing carousel with 5 client reviews
8. **Gallery** — Masonry-style logistics image grid
9. **FAQ** — Animated accordion with 8 questions
10. **Contact** — Form with validation, WhatsApp CTA, Google Maps embed
11. **Footer** — Full footer with newsletter, social links, and quick links

## Features

- Sticky navigation with scroll-aware active state
- Dark/light mode toggle (persisted to localStorage)
- Floating WhatsApp button and back-to-top button
- CSS-only scroll reveal animations via IntersectionObserver
- Fully mobile-responsive with mobile hamburger navigation
- SEO-optimized meta tags, Open Graph, and semantic HTML

## Running Locally

```bash
npm install
npm run dev       # Development server on http://localhost:3000
```

The Netlify CLI also supports local emulation with:
```bash
netlify dev       # Local server on http://localhost:8888
```
